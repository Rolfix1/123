# ВЕКТОР

Одностраничный сайт вымышленного автосервиса и закрытая страница владельца.

## Запуск в PowerShell

Нужен Node.js 24. В папке проекта выполните:

```powershell
$env:OWNER_PASSWORD = Read-Host 'Пароль владельца (от 12 символов)' -MaskInput
node server.mjs
```

Сайт откроется по адресу http://127.0.0.1:3000, заявки доступны владельцу по адресу http://127.0.0.1:3000/owner. По умолчанию база SQLite хранится в локальной папке приложения `VectorGarage`. Можно указать абсолютный путь в `VECTOR_DB`.

При размещении используйте HTTPS, включите `SECURE_COOKIE=1` и поместите SQLite на постоянный том. По умолчанию процесс слушает только localhost. Для контейнера адрес можно задать через `HOST`, порт через `PORT`. Страница владельца показывает до 200 последних заявок.

Бренд, цены, гарантия, опыт и отзывы придуманы для демонстрации. Для публичного кейса используйте вымышленные данные при заполнении формы. Сравнение иллюстрирует изменение изображения.
